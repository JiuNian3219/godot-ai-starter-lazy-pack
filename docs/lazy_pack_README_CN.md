# Godot AI Starter Lazy Pack

这个安装包把 Godot 4.7.1 + GDScript 开发模板安装到新项目。AI 按外层 INSTALL.md 安装，开发时按项目 AGENTS.md 工作。

## 创建新项目

把本安装包和目标目录交给 AI，让它完整阅读并执行包根目录的 `INSTALL.md`。该文件由源码 `docs/next_project_prompt.md` 直接复制，包含依赖检查、引擎确认、安装和验证的完整步骤。

使用已提供的包，不自动换成其他 Release。含引擎 ZIP 携带 Windows x64 Godot 4.7.1；轻量 ZIP 使用本机兼容引擎。安装只用于创建新项目，不覆盖已有游戏。

## 开发时怎么用

直接向 AI 描述需求。你整理的游戏文档放在新项目的 `docs/项目说明.md`，也可在其中链接已有资料；AI 按 AGENTS 在任务中读取和使用。AGENTS 保留核心规则；AI 先查 Error 索引，命中后读对应经验，按任务读专项规则。关键玩法计算、状态归属和先后顺序应能从代码看清。

AI 代码变更验证通过后默认提交本次相关文件，除非用户禁止；使用 Conventional Commits，不包含无关改动与生成物。普通功能以技术验证为主，正式试玩只在用户声明垂直切片时进行。

保留素材的来源和许可证登记在 Excel 台账中，随素材变更更新；生成提示词可选。项目文档由用户主导整理，不自动写总结、决策或交接记录。

## 包含与边界

开发项目获得规则、错误索引、资产台账、Godot MCP、示例场景、测试和验证脚本。完整清单见外层 TEMPLATE_MANIFEST.md。安装说明和维护资料留在包外层，不带入游戏项目。

初始场景、脚本及对应测试只是可替换示例。验证入口启动当前主场景，并自动运行 `tests/**/*_test.gd`；无需保留模板的 Title 节点或旧场景路径。

源码构建方式见仓库 README。引擎二进制、`.godot/`、`.tmp/`、本地路径配置、构建和导出文件不提交。
