# Decision Records

This folder stores durable project decisions.

Use a lightweight ADR format:

```text
# NNNN Title

Status: Proposed | Accepted | Superseded
Date: YYYY-MM-DD

## Context

What problem or tradeoff forced this decision?

## Decision

What did we choose?

## Consequences

What gets easier, harder, or constrained because of this?

## Verification

How do we know this decision is still working?
```

Create one ADR per durable decision. Keep each ADR short enough that an AI agent will actually read it.
